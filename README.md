# MenuOptimizer

A full-stack restaurant menu optimization project with a Python backend and a React frontend.

## Structure

- `backend/` - Flask API, database, parser, PDF generation, pricing logic
- `frontend/` - React app for uploading and reviewing optimized menu output

## Quick start

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Features

- Upload restaurant menu files
- Parse and normalize menu data
- Optimize dish descriptions and pricing
- Generate a downloadable PDF menu
- Store menu information in SQLite
